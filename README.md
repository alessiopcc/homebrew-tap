# alessiopcc/homebrew-tap

Homebrew formulas for tools by [@alessiopcc](https://github.com/alessiopcc), for macOS and
Linux.

```sh
brew install alessiopcc/tap/glidesh
```

or add the tap once and install by name:

```sh
brew tap alessiopcc/tap
brew install glidesh
```

Upgrade with `brew upgrade glidesh`; remove with `brew uninstall glidesh` (and
`brew untap alessiopcc/tap`).

| Formula | Description |
|---|---|
| [glidesh](https://github.com/alessiopcc/glidesh) | Fast, stateless, SSH-only infrastructure automation |

Formulas install the prebuilt binaries from each project's GitHub release, checked against
its SHA-256. They are updated by each project's release workflow; do not edit them by hand.
